# Formulários Elegis

Este repositório contém formulários desenvolvidos para o sistema Elegis.

## Formulários Disponíveis

### Formulário de Procuração
Formulário para solicitação de procurações, com suporte para:
- Pessoa Física
- Pessoa Jurídica
- Partido Político ou Federações
- Coligação - Representante de Coligação

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript (Vanilla)
- Webhooks para processamento de dados

## Como Usar
1. Clone o repositório
2. Abra o arquivo HTML desejado em um navegador
3. Preencha o formulário
4. Os dados serão enviados para o webhook configurado
